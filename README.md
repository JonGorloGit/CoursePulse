# CoursePulse

Collective classroom reflection, not grading. Students submit text and artifacts; an OpenAI model synthesizes themes, open questions, tensions, surprises, muddiest points, missing perspectives, discussion prompts and a Meme Corner.

## Render deployment

The repository includes `render.yaml` for a Render Blueprint with a Node web service and PostgreSQL database.

Required secret: `OPENAI_API_KEY`.

`ADMIN_KEY` is generated by Render. Copy it from the service Environment page; instructors enter it when opening the dashboard.

## Local

Set `OPENAI_API_KEY`, `DATABASE_URL`, and `ADMIN_KEY`, then `npm install && npm start`.

## Privacy / teaching design

CoursePulse intentionally avoids individual scores, rankings and student profiling. For real teaching use, establish an institutional data-protection basis and retention policy before collecting student artifacts. Do not ask students to upload sensitive personal data.
